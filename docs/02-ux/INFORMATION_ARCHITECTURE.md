# DOC-02 情報設計・画面遷移

## ナビゲーション
トップナビは `TODAY` / `WORK` / `KNOWLEDGE`。右上の「承認 n件」は横断キューへのショートカット。詳細設定・監査・能力評価は二次メニュー。

```mermaid
flowchart TD
 O[初回設定 SCR-00] --> T[今日 SCR-01]
 T --> W[仕事一覧 SCR-02]
 T --> K[知識検索 SCR-04]
 T --> A[承認一覧 SCR-06]
 W --> D[仕事詳細 SCR-03]
 D --> A
 D --> E[根拠・実行履歴 SCR-08]
 K --> N[知識詳細 SCR-05]
 N --> A
 A --> C[差分・承認 SCR-07]
 T --> S[設定・接続 SCR-09]
 T --> V[成長評価 SCR-10]
 S --> O
 C --> D
 C --> N
```

## 横断UX
- 全画面に接続状態と最終同期時刻（不明なら不明）を表示する。
- 高リスクアクションは、対象・効果・不可逆性・必要な権限を確認。
- コンテンツなし/読み込み中/停止中/競合/権限不足/索引遅延/機密拒否/再試行不能を各画面で定義。
- スマホでは確認・承認・通知に重点を置き、差分が大きい場合はPCでの確認を推奨。
